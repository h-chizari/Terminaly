# ASD-STE100 Simplified Technical English Prompting Guidelines

When executing AI coding and technical reasoning tasks with Terminaly:
1. **Be Specific and Direct**: Use active voice. Write short, clear sentences containing only one thought or requirement.
2. **Standard Terminology**: Use approved technical terms consistently without ambiguous synonyms.
3. **Action-Oriented Verbs**: Start procedural steps with imperative verbs (e.g., "Compile", "Extract", "Verify", "Replace").
4. **No Speculation**: State known facts, requirements, and measured constraints directly. Avoid fluff and filler phrases.
5. **Clear Preconditions and Postconditions**: Specify exact input shapes and expected outputs for every function or shell utility.
